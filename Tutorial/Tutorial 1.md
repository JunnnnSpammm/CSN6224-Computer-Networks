## Part A: Structured

### 1. List out the five components of a data communication system.
Message, receiver, sender, protocal, transmission medium

### 2. What are the three most important network criteria must be meet for an effective and efficient network?
Performance, reliability, security

### 3. What are two types of line configuration?
Point-to-Point and multipoint

### 4. What is the difference between half-duplex and full-duplex transmission?
Half-duplex only allow one direction at a time, meaning if a device is sending, the other device can only receive. Full-duplex allow transmission simultaneously in both directions, where both devices can receive and send message at the same time.

### 5. Calculate the required number of cables for each type of the network below:
#### a. Mesh.
Number of cables = $\frac{n(n-1)}{2}$

#### b. Star.
Number of cables = $n$

#### c. Ring.
Number of cables = $n$

#### d. Bus.
Number of cables = $n+1$

### 6. What is an internet? What is the Internet?
An internet is short for internetwork, where two or more interconnected networks that can communicate with one another. The Internet is a specific, global system of interconnected computer networks using the TCP/IP protocol suite to link billions of devices worldwide.

### 7. Why Standard is needed in telecommunication?
* Ensures hardware and software from different manufacturers can communicate seamlessly across networks. 
* Prevents vendor lock-in and encourages multiple vendors to compete on quality, features, and price. 
* Provides consistent specifications so networks can grow and integrate easily while maintaining predictable behavior. 
* Helps ensure equipment meets legal, frequency, and safety requirements across regions.
